# Brand Skinning Checklist

Reference list of what actually changes when re-skinning a Feed prototype from its demo brand to a real client brand. Worked example below is the Point Taken skin (built on top of the "Urban Performance" menswear demo). Use this as the checklist when skinning the next prototype — same categories, different brand.

## Point Taken (from "Urban Performance")

- Renamed the demo brand everywhere — the URL entry screen, the setup rail, the workspace name, and every line of feed/deck/story/history copy — from the old "Urban Performance" menswear demo to "Point Taken."
- Prefilled the brand's own URL (pointtaken.in) as the default so the demo opens already configured for them.
- Switched the product category from generic menswear to Indo-Western fusion/ethnic fashion, and introduced the brand's actual product line names into the copy: Made to Layer, The Jaipur kurta, The Mulmul kurta, The Dhoti pant.
- Updated the competitor set shown in the AI-visibility cards to the brand's real competitors: FabIndia, Global Desi, House of Indya.
- Replaced generic stock photography (Pexels) with real product photography from the brand's own catalog source, because stock people read as "regular people" instead of the polished editorial look the brand wanted.
- Made every post image and loading skeleton render as a consistent square, cropped from the top so the crop trims off the bottom of the photo, not the face.
